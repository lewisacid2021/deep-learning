# 神经网络

## 激活函数

将加权输入信号的总和转换为输出的函数

激活函数是连接感知机和神经网络的桥梁

激活函数从**阶跃函数**换为其他函数，就来到了神经网络的领域

---

### 1. 阶跃函数

$$
\text{step}(x)=
\begin{cases}
1, & x > 0 \
0, & x \le 0
\end{cases}
$$

---

### 2. sigmoid函数

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

---

### 3. ReLU函数

$$
\text{ReLU}(x)=\max(0,,x)
$$

---

### 4. Softmax 函数

$$
\text{softmax}(x_i)=\frac{e^{x_i}}{\sum_{j=1}^{n} e^{x_j}}
$$

- softmax函数的输出位于0.0-1.0之间,且输出值的总和为1,符合**概率**的性质

---

感知机中神经元之间流动的是**0 或 1**的二元信号,而神经网络中流动的是**连续的实数值**信号

神经网络的激活函数必须是非线性函数，不然层数就失去意义了（嵌套几层都是线性，可以由无隐藏层的神经网络替代）


输出层的激活函数选择与中间层不同，要看求解问题的性质决策，一般地：
- 回归问题使用恒等函数
- 二元分类问题使用sigmoid函数
- 多元分类问题可以使用softmax函数

前向（forward）指从输入到输出方向的传播处理

求解机器学习问题的步骤可以分为“学习”A 和“推理”两个阶段。
- 首先,在学习阶段进行模型的学习 B
- 然后,在推理阶段,用学到的模型对未知的数据进行推理(分类)。

如前所述,推理阶段一般会省略输出层的 softmax 函数。在输出层使用 softmax 函数是因为它和神经网络的学习有关系(详细内容请参考下一章)。
