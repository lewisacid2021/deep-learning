# 感知机

## 感知机的局限性

感知机本质上是分割值域空间

对于2个信号逻辑运算的真值表来说：
- 异或运算无法用**直线**分割，因此**单个感知机**实现不了异或门

## 线性和非线性

曲线分割而成的空间为**非线性**空间

直线分割而成的空间为**线性**空间

## 多层感知机

使用与非门、或门和与门实现**异或**门，实际上是2层感知机

第0层->第1层->第2层

也有文献称为3层感知机（无权重输入的第0层也计入）

通过*叠加层*，感知机可以更加灵活的表示

## 总结

- 感知机是具有输入和输出的算法。给定一个输入后,将输出一个既 定的值。  
- 感知机将权重和偏置设定为参数。  
- 使用感知机可以表示与门和或门等逻辑电路。  
- 异或门无法通过单层感知机来表示。  
- 使用 2 层感知机可以表示异或门。  
- 单层感知机只能表示线性空间,而多层感知机可以表示非线性空间。  
- 多层感知机(在理论上)可以表示计算机。
